- The C/C++ dependency scanners now recognise the C23 #embed directive.
  An embedded resource is tracked as an implicit dependency, so changing
  it rebuilds the source file that embeds it. A quoted resource name is
  looked for relative to the including file, a bracketed name in
  $CPPPATH; note compilers use a separate search path for the bracketed
  form (--embed-dir=), so those directories need to be added to $CPPPATH
  as well.

FIXES

- Fix ninja to honor AlwaysBuild on a target

  instead of splitting at the first colon.

- Fix documentation processing to work with lxml 6.1.3 and newer, which no
  longer resolves external parameter entities by default. This affects both
  the SCons documentation build and the docbook tool, which failed on any
  DocBook source pulling in an external entity module.
